## Compact Rules (auto-resolved, inject into sub-agent prompts)

**Stack & tooling**
- pnpm exclusively; never `npm install`/`yarn install`. Never add a second lockfile.
- `pnpm build` = `tsc -b && vite build && node scripts/copy-404.mjs`.
- `pnpm test` = vitest run; `pnpm e2e` = `pnpm build && playwright test`.
- `pnpm run audit:collage` (never bare `pnpm audit`) — occlusion/target-size/clipped-text audit at 1440/1280/1100/390px.

**Design law (non-negotiable)**
- Exact hex values + contrast ratios in `docs/02_DESIGN_SYSTEM.MD` / `docs/05_ACCESSIBILITY.MD` are LAW. Never invent a new accent color without contrast-checking and documenting the ratio.
- `border-radius: 0` everywhere, no exceptions.
- Home layout follows `docs/12_COLLAGE_SYSTEM.md` (overlap/collage grid over bleeding halftone hero) — this SUPERSEDES the dashboard-grid description in `docs/11_HANDOFF_HOME.md`.
- Decorative auto-playing animations: fully `aria-hidden`, never receive focus, dismiss on any keypress; the same info (name/role/etc.) must independently exist in accessible markup elsewhere on the page. Reference: `docs/05_ACCESSIBILITY.MD` "Decorative / Auto-Playing Animations".
- Doc conflicts: later dated correction wins — check "Updated"/"SUPERSEDED" notes at top of each doc.

**Session hygiene**
- Ad-hoc probe scripts/screenshots → session scratchpad, never repo root. Committed tooling → `scripts/` or `tools/`.
- Never delete an untracked file without explicit user confirmation — move to `_quarantine/` (gitignored) instead.
